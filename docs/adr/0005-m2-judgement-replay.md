# M2：同步判定 + 动作重演回放

M2 引入判定系统，采用两个绑定决策（2026-10-05）：

1. **判定同步化**：判定直接从牌堆顶翻牌即时结算（八卦阵、乐不思蜀、兵粮寸断、闪电），不设"改判"询问时序，也无判定过程中的插结算。理由：M2 的武将技能全部是使用/打出转换类（武圣、龙胆、咆哮），没有改判类技能；异步判定引擎复杂度翻倍而当前无收益。M2 范围内的判定点是纯随机翻牌，同步化是零信息损失的简化。若未来引入改判技能（司马懿鬼才/张角鬼道），需把判定升级为 pending 询问流——这是有意识的债务。
2. **回放 = seed + 动作重演**：GameState 记录 actionLog，回放查看器不存快照，而是从 setup(seed) 逐步重放动作重建任意时刻状态。引擎本身确定性可复现（ADR-0002 的种子随机），重演天然正确；代价是回放跳转 O(步数)，可接受。

# M16：武将池扩至 25（张辽/许褚/郭嘉/黄月英/吕蒙/陆逊）——标准版封顶

M11–M15 把规则、AI 与界面补齐后，武将池仍差标准版的最后 6 人（2026-10-06 定）。
这 6 人各自带来一个此前没有的机制，因此没有一个是"填数据"式的扩展：摸牌阶段的
抉择（突袭/裸衣）、伤害后摸牌并**分配**（遗计）、判定牌归属（天妒）、出牌以外的
技能触发钩子（集智/连营）、以及三条锁定技（奇才/谦逊/克己）。

1. **张辽·突袭 / 许褚·裸衣：摸牌阶段第一次成为"抉择点"**。新增询问
   `drawPhase`——摸牌阶段开始时若持有这两个技能，先问一次：突袭（放弃摸牌，
   改为获得至多两名其他角色各一张手牌，新询问 `tuxi` 选目标）或裸衣（少摸一张，
   本回合【杀】/【决斗】伤害 +1）或正常摸牌。`GameState.damageBonus` 承载裸衣的
   伤害加成，在杀命中与决斗落败两处生效、回合结束清零。
2. **郭嘉·天妒 + 遗计**。天妒在 `resolveJudge` 里截胡判定牌（不再进弃牌堆，
   直接入手）——这是判定链自 M4 以来第一次有"判定牌归属"的变化。遗计在
   `dealDamage` 里按**伤害点数**摸 2×N 张，然后逐张开 `yiji` 询问分配；因为
   triggerQueue 按 sub+playerId 去重，多次连续受伤会把待分配牌**累加**（改了
   `queueTrigger` 的合并语义）。
3. **黄月英·集智 + 奇才**。集智挂在 `playTrick` 上（非延时锦囊摸一张；延时锦囊与
   无懈不算）；奇才是锁定技，把顺手牵羊/兵粮寸断的距离校验改为"奇才则免检"。
4. **吕蒙·克己**。弃牌阶段前判 `shaUsed`（本回合是否使用或打出过杀），未用则跳过
   弃牌——为此新增 `GameState.shaUsed`，在 `playSha` 与 `respondSha` 两处置位。
5. **陆逊·谦逊 + 连营**。谦逊在目标校验处拦顺手牵羊与乐不思蜀（AI 与 MC 的候选集
   同步排除，否则自己生成非法动作）。连营是**钩子而非事件**：手牌离开的路径太多
   （出牌/应答/弃置/被夺），逐个插钩必然漏，改为在 `step()` 首尾各比对一次
   "动作前有牌、动作后无牌"的持有者（`checkLianying`），靠去重避免重复触发。
6. **孙尚香·结姻**（补她本就该有的第二个技能）：弃两张手牌与一名已受伤男性各回
   1 点，走通用主动技三步机（`activeMode: 'jieyin'`）。
7. **AI**：摸牌抉择（张辽有目标就夺、许褚有杀且体力≥3 才裸衣）、突袭目标（手牌
   多的敌人优先）、遗计分配（手牌不紧张时给最缺血的盟友）、结姻时机（手牌≥3 且
   己方有伤者）。
8. **顺带修一处观测盲区**：铁骑此前只在判定为红时记 skill 事件，判定为黑则日志
   里完全看不到它发动过——回归护栏一上线就暴露了这一点（40 局内 0 次）。现改为
   "发动即记技能事件、结果另见 judge 事件"。

## 已知简化（记录在案）

- 突袭**只能夺手牌**、不可选装备，且手牌随机抽取（与原版一致的部分）；被夺者
  手牌为空时不可选（AI 与引擎同步）。
- 裸衣的伤害加成只作用于【杀】与【决斗】（原版也是），不作用于刚烈/闪电等无来源
  伤害；加成按"来源的 damageBonus"取，而非"伤害瞬间谁在回合内"。
- 遗计分配是**逐张询问**，不是一次选定全部；AI 的分配策略只看"最缺血的盟友"，
  不做牌质量匹配（好牌该给谁）。池中牌全部分完或用户全部留给自己才结束。
- 天妒与遗计叠加时（郭嘉同时受判定与伤害）互不干扰：天妒在判定链、遗计在伤害入口。
- 连营的两次检测（apply 后与 advance 后）依赖 `queueTrigger` 的同技能去重；若未来
  加入"连营限一次每回合"之类的限制，需要重新设计去重键。
- 奇才对 AI 只放宽"顺手牵羊/兵粮寸断"两处距离校验；MC 候选集里仍按保守距离，
  即 MC 可能低估黄月英的可及范围（不影响合法性）。
- 谦逊拦的是"指定目标"；五谷丰登的亮牌、桃园结义的回血等无目标选择的部分不受
  影响（与原版一致）。

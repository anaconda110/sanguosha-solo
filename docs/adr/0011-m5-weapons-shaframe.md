# M5：武器特效补齐与 ShaFrame 统一杀结算

M5 把 ADR-0010 遗留的武器特效全部补齐，为此把【杀】的结算从"直接置 pending"升级为
ShaFrame 帧（与锦囊帧共用帧栈推进），并引入性别与新武将孙尚香（2026-10-06 定）。

1. **ShaFrame 统一杀结算**：`startSha` 现在压入 `{kind:'sha', userId, cardId, targets, idx, cixiongDone}`
   帧，逐目标推进：雌雄选择 → 出闪（无双 needShan，青釭剑无视八卦）→ 命中/闪避（青龙刀/贯石斧）。
   单目标与方天多目标走同一条路径；青龙刀"再杀"通过"外层帧先 advance 再压新帧"实现嵌套，
   避免外层帧重复询问同一目标。
2. **青釭剑**：来源装备时目标八卦阵无效（stepSha 跳过 shield，pend.qinggang 标记门禁
   respondBagua——引擎校验、AI、UI 三层都拦）。
3. **雌雄双股剑**：对异性目标每目标一次（cixiongDone 记账）；目标有手牌时以 cixiong 询问
   （弃一张手牌→杀无效，走 discard 流程收尾；或来源摸一张）。池内只有孙尚香为女性。
4. **丈八蛇矛**：playSha 新增 cardId2（两张手牌当杀）；仅"使用"支持，"打出"（南蛮/决斗）不支持。
5. **贯石斧**：shaDodged 挂钩，杀被闪避后来源手牌≥2 可弃两张手牌强行命中（简化：仅手牌，
   不含装备区）。
6. **方天画戟**：playSha 新增 targetIds（2-3 目标），要求杀是最后的手牌（cardId2 时为两张）
   且各目标合法在射程。日志 playCard 带 targets 数组，UI 箭头逐目标绘制。
7. **性别**：GENERAL_SEX 表 + PublicPlayer.sex；UI 座次显示 ♂/♀（♀高亮）。
8. **孙尚香·枭姬**（trigger）：失去装备区一张牌后摸两张。挂钩三处装备移除点
   （resolvePickFrom/discardMount/playEquip 替换——替换处补上了此前缺失的 unequip 事件）；
   死亡清算不发 unequip 事件，故不触发（符合原版）。
9. **AI 鬼才接上**（清偿 ADR-0010"AI 不发动鬼才"）：只优化自己的判定——八卦要红、
   乐要红桃、兵避草花、闪电避黑桃2-9；需手牌≥2，优先弃最不值钱的牌。他人判定不掺和。

## 已知简化（记录在案）

- 贯石斧只能弃两张手牌（原版可含装备区）。
- 丈八蛇矛不能用于"打出"（南蛮/决斗应答），只能用于"使用"。
- 方天画戟多目标 + 丈八两牌组合：引擎支持（cardId2+targetIds，两张即最后手牌），
  但 UI 与 AI 都不产生该组合（UI 方天仅单卡选中时开放）。
- 雌雄双股剑默认视为来源必发动（原版为可选）。
- AI 鬼才只防御性改判自己的判定，不进攻性改判（如把闪电改成黑桃2-9砸下家）。

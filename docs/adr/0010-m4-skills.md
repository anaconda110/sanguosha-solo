# M4：武将技能四类与判定链升级

M4 把武将从 3 名扩到 8 名，为此把技能系统从"内联 if"升级为四类显式机制（2026-10-05 定）：

1. **技能注册表（skills.ts）**：hasSkill/canActAsSha/canActAsShan/hasShaMaterial 成为引擎与 AI 的共用静态查询；武圣/龙胆不再内联在 step.ts 里判断。
2. **触发技队列**：伤害结算时将可发动技能（奸雄/反馈）入 triggerQueue；pending 清空后、帧推进前按队列逐个询问（trigger 询问，真人按钮、AI 一律发动）。死亡玩家从队列跳过。
3. **主动技**：play 询问新增 useSkill 动作；苦肉（失 1 体力摸 2 张）每回合限一次，用 usedSkills 记账（回合结束清空）。失去体力走 hurt()（damage 事件带 loss:true，无伤害来源，不触发反馈）。
4. **判定链升级（清偿 ADR-0005 债务）**：判定从同步翻牌改为 judgeState 上下文——翻开判定牌 → 鬼才询问链（从判定者起按座次，每人每判定至多一次，可放弃）→ 生效。生效时判定牌进弃牌堆；延时锦囊本体按效果处置（乐/兵弃置、闪电命中弃置/否则转移）。八卦阵出闪判定复用同一条链。
5. **伤害因果线程**：TrickFrame 记录使用者打出的 cardId，杀询问记录 shaCardId，随伤害传入——奸雄据此取回"造成伤害的牌"。
6. **无双（吕布·锁定）**：使用杀需两张闪（needShan/shanPlayed 计数）；决斗中打出两张杀（duelShaPlayed 计数，逐张询问）。

## 已知简化（记录在案）

- AI（规则+MC）不发动鬼才（询问会应答"不替换"）；苦肉仅在 hp≥3 且手牌≤3 时发动。
- 雌雄双股剑/丈八蛇矛/方天画戟/青龙刀的额外效果中，仅青龙刀（再杀）已实现，其余三个仍待办（需要性别、多目标杀、弃两张的支撑）。
- 奸雄只回收造成伤害的那张牌（不含连锁伤害的间接因果）。

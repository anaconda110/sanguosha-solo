# M8：大乔（国色/流离）、甘宁（奇袭）与武将图鉴

M8 新增第 13、14 名武将，引入两个新机制层：锦囊转换（use 类技能第一次覆盖锦囊）
与流离的杀目标转移（2026-10-06 定）。

1. **锦囊转换层**：`asTrickSub(p, card)` 返回这张牌作锦囊使用的生效牌名——
   **天然锦囊一律按原牌名**（转换技不覆盖天然锦囊，否则黑色南蛮会被奇袭"吞掉"）；
   非锦囊牌走转换：国色方块→乐不思蜀、奇袭黑牌→过河拆桥。playTrick 校验与应用
   全部基于 asSub；转换发生时记 skill 事件（guose/qixi）。
2. **判定区记转换牌名（asSub）**：转换放置的延时锦囊在 judgements 里以
   `{...card, asSub}` 存放；判定区所有读点（重复检查/判定帧 sub/无懈作废查找/
   view 展示/AI 目标筛选）统一走 `zoneSub(c) = c.asSub ?? c.sub`。牌离开判定区
   入弃牌堆时 `delete asSub`（闪电转移时保留）。卡牌本体不变——回到弃牌堆后被
   再摸起仍是原牌。
3. **流离（trigger）**：stepSha 在雌雄之后、出闪询问之前，对持有流离、尚有手牌、
   且距离1内有其他男性（非杀使用者）的目标发 liuli 询问。respondLiuli 弃一张
   手牌并把 `frame.targets[idx]` 直接换人——不调用 advanceSha，advance 重新推进
   stepSha，新目标自然获得雌雄/流离/出闪的完整处理。`liuliDone`（每目标一次）
   防止两名流离持有者互相甩杀死循环。
4. **武将图鉴**：header"武将图鉴"按钮展开 14 名武将的全部技能与描述（纯 UI）。
5. **AI**：奇袭用黑色非锦囊牌当拆、国色用方块非锦囊牌当乐（与引擎"天然锦囊不转换"
   对齐——首跑回归连抓两处 AI 拿天然锦囊当转换素材的崩溃）；流离在手牌≥2 时
   弃最不值钱的牌把杀甩给距离内男性敌人。

## 已知简化（记录在案）

- 天然锦囊不能被转换使用（经典规则允许甘宁把黑色南蛮当拆——这里强制按原牌名，
  否则动作无法表达意图；黑无懈只能当无懈）。
- 流离只能弃手牌（原版可弃装备区牌）。
- UI 里国色/奇袭不能选装备牌作素材（点击装备一律装备），AI 可以。
- 洛神+倾国使甄姬在规则 AI 自战中近乎不死，极端局（如 seed 5，2.2 万步）靠
  回合熔断终局——draw 计数从 M7 的 2 涨到 3；真人局不受影响。

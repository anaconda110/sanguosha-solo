# M7：诸葛亮（观星/空城）与甄姬（洛神/倾国）

M7 新增第 11、12 名武将，引入三个新引擎机制：准备阶段钩子、观星牌堆操作、
洛神判定循环（2026-10-06 定）。

1. **准备阶段钩子**：GameState 新增 `prepared`（endTurn 重置）。advance 在进入判定
   阶段前一次性处理：观星持有者 → guanxing 询问（翻看牌堆顶 X = min(存活数,5) 张）；
   洛神持有者 → luoshen 入触发队列。顺序保证：触发队列 → 判定链 → 判定阶段帧，
   恰好是原版"准备阶段 → 判定阶段"的时序。
2. **观星（active，准备阶段）**：询问携带 guanxingCards（已从牌堆顶弹出）。
   respondGuanxing.topIds[0] 最先被摸到——置顶逆序压回（deck 顶 = 数组尾），
   未选的按原顺序置底（unshift）。AI 策略：全部置顶按价值降序（桃多为红桃，
   顺带提高自家判定红桃率）。
3. **洛神（trigger，准备阶段）**：respondTrigger 发动 → beginJudge(mode 'luoshen') →
   判黑：判定牌从弃牌堆收回手牌、重新入队继续判定；判红：终止。鬼才链对洛神
   判定同样生效。AI 收手条件：手牌 ≥8 不再发动（无脑连发曾把局均步数推高 3 倍）。
4. **空城（lock）**：`isKongcheng(p)` = 有技能且无手牌；【杀】（单/多目标）与
   【决斗】的目标校验统一引用；规则 AI 与 MC 候选同样过滤。AOE（南蛮/万箭）
   不受空城保护（原版如此，非"指定目标"）。
5. **倾国（use）**：黑色手牌当【闪】，并入 canActAsShan（桃必为红色，不会被误出）。
   UI 出闪按钮对甄姬放开黑色手牌选项。
6. 牌堆顶约定：`deck` 数组尾 = 顶（deck.pop 取牌）。观星是首个"把牌放回牌堆"的
   操作，smoke 的卡牌守恒记账已加入"观星询问中持有的牌"。

## 已知简化（记录在案）

- AI 观星全置顶按价值排序，不做"给下家留烂牌"的博弈。
- AI 洛神只看手牌数收手，不看牌堆剩余构成。
- 离间可以指定空城男性为目标（虚拟决斗不受空城限制，取官方裁定的宽松解释）。
- 观星询问的 guanxingCards 经 view.pending 对所有视角可见——本作信息隔离本就
  只做 UI 层（pend 过滤为自家询问），不构成额外泄露面。
- AI 变强（观星/倾国/无懈）使 AI 自战局均步数从 ~240 涨到 ~830，最长 2.4 万步；
  浏览器真人局不受影响，不改 MAX_TURNS（5000 回合熔断未触发）。

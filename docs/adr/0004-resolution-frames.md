# 结算栈（帧机）与 M1 范围简化

锦囊牌的结算需要嵌套暂停/恢复：南蛮入侵要逐目标询问出杀、每个目标前还有无懈可击询问、伤害又可能触发濒死求桃链——原有的"隐式流程推进 + 单一 pending"模型表达不了这种嵌套。M1 引入结算栈：每张需要多步结算的锦囊压入一个帧（目标队列、当前下标、无懈询问记录、决斗轮转），advance() 优先消费栈顶帧，帧可被 pending 打断并在其清空后自动续走；濒死求桃等全局打断不触碰帧。出牌阶段的动作一律先清空 play 询问，帧清空后由阶段机重新派发——play 询问不再"粘"在手牌动作上。

## M1 范围简化（记录在案，防止被当 bug"修复"）

- 无懈可击只做单轮询问：一张无懈直接抵消该目标的效果，不做反无懈嵌套（M2 视需要加）。
- 无懈只响应进攻性锦囊（拆/顺/决斗/南蛮/万箭）；无中生有、桃园结义不设无懈询问。
- 武器只实现范围与两个效果：诸葛连弩（出杀不限次）、麒麟弓（命中弃马，锁定简化）；其余武器先作纯范围件，触发技随 M2 技能系统补。
- 防具（八卦阵）依赖判定系统，整体推到 M2。
- 牌堆为自定义 94 张（非标准 108），M2 再对齐。
- 每条求桃询问链中每名玩家至多使用一张桃。

# M6：貂蝉（离间/闭月）与 AI 无懈可击

M6 新增第 10 名武将貂蝉，离间是首个"弃牌 + 多目标"主动技；同时把 A1 起挂账的
"AI 不使用无懈可击"清掉（2026-10-06 定）。

1. **离间（active）**：`useSkill` 动作扩展 `cardId`（弃置的手牌）与 `targetIds`
   （两名男性，前者为决斗使用者）。引擎一次性校验（每回合限一次、手牌、两名不同
   存活男性），随后压入一张真实的 juedou TrickFrame——被弃手牌作帧的因果牌
   （奸雄可取回），wuxie 阶段自然生效（可被无懈抵消）。决策一次提交，无中间询问。
2. **闭月（trigger，自动发动）**：endTurn 开头对存活貂蝉摸一张牌并记 skill 事件。
   位于弃牌阶段之后，手牌可超体力上限（符合原版时序）。简化：不询问真人
   （永远划算，省一次点击）。
3. **AI 无懈可击**：respondWuxie 决策——自保（自己是当前结算目标就抵消）+ 忠内保
   主公（锦囊/延时锦囊目标为主公时抵消）；不无懈自己使用的锦囊。反贼不为队友
   交代无懈（记录在案）。
4. **AI 离间**：两名男性敌人在场且手牌≥2 时发动；杀素材多者当决斗使用者（更可能
   赢得决斗），弃最不值钱的一张牌。
5. UI：离间三步交互（按钮 → 点一张手牌 → 点两名男性座次，集齐自动提交）；
   貂蝉/孙尚香头像配色补齐（M5 漏了孙尚香映射，已补）。

## 已知简化（记录在案）

- 离间的使用者/目标顺序固定为"先选者出决斗"（原版可选任意一方为使用者）。
- 闭月自动发动，无"发动/不发动"询问。
- AI 无懈只自保与保主公：不救忠臣/队友，不做无懈对无懈的博弈。
- MC 根决策（首个出牌动作）不含离间候选；离间由规则 AI 在后续决策点发动
  （MC 仿真内的 rollout 会通过 ruleAction 正确模拟它）。

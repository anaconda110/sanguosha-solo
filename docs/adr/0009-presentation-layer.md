# M3 演出层：事件驱动动画 + 环形桌位 + 占位立绘

演出（动画/指示/指向）与逻辑解耦：每次 step() 附加的事件差分映射为 CSS 动画——座次间指向连线（约 500ms 淡出，降级为目标高亮 + 飘出牌名）、目标受击闪烁、思考指示器、濒死/判定/游戏结束的关键高亮——引擎零改动（ADR-0002 分离设计的红利）。桌位改环形布局：自己固定在下，其余四家按座次分布于左/上/右，中央为牌堆/弃牌堆与回合信息区（仿原版）。手牌按类型（基本 → 锦囊 → 装备）与花色点数排序，增删以 FLIP 动画过渡。武将立绘采用程序生成的占位徽章（SVG 渐变 + 汉字），守住 ADR-0001 零版权红线；素材接口预留本地替换口——无名杀等 GPL 素材仅限本地自用、永不入库。

## Consequences

- 演出层只消费事件日志，不回写引擎状态；动画节奏（约 550-800ms/事件）由 UI 层自调，不影响引擎确定性。
- 占位立绘与素材替换接口分离，后续接真素材包不触碰规则代码。

# M3 交互批：AI Worker 化 + 选牌询问

A2 的蒙特卡洛决策在主线程同步执行，每回合开局冻结 UI 1-2 秒——ADR-0006 记录的取舍于 2026-10-05 被决策者判定不可接受（主诉："操作太平面化，看不到交互"）。决定两项：

1. **MC 移入 Web Worker**：引擎是纯逻辑库（ADR-0001/0002 分离设计的红利），主线程发送剥离日志的状态快照，Worker 返回 Action，主线程应用；Worker 不可用（如 file:// 直开构建产物）时自动回退主线程同步计算。主线程从此零冻结。
2. **拆/顺新增选牌询问**：过河拆桥/顺手牵羊结算帧增加"选牌"阶段——使用者在目标的装备明牌中点选，或从手牌暗牌中随机抽一张（仿原版交互）；引擎新增 pickCard 询问类型，AI 应答策略为武器 > -1马 > +1马 > 手牌随机。

## Consequences

- 状态快照剥离日志后，Worker 内 rollout 的日志拼接链从空表开始——仿真不读日志，无影响。
- 选牌询问复用 ADR-0004 帧机的"暂停-恢复"机制，不引入新并发模型。
- 选牌是引擎级改动（新询问类型 + 帧阶段），非纯 UI 功能——回放与 AI 应答链路同步受益。

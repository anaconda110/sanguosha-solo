# M18：体验批三——AI 难度分级、音效、设置面板

M15 补完存档/观战后，"玩家能玩"还差三块体验件（2026-10-06 定）：难度没有分级
（对手永远开蒙特卡洛）、完全静音、没有任何设置入口。这批把三者一次补齐，同时
把最初 C 选项清单上最后一项（AI 难度开关）落地。

1. **AI 难度分级**：`aiAction(s, playerId, difficulty)` 增加 difficulty 参数——
   `easy` 档跳过回合首决策的蒙特卡洛（ADR-0006），全程规则表；`normal` 维持现状。
   难度经 Worker 的 `AiRequest` 下传。**实测**：同一局面 easy 0ms / normal 311ms。
   定位是"简单档响应快、适合观战与新手"，不是"弱智化"——规则表本身不弱。
2. **音效（src/sound.ts）**：WebAudio 程序合成，**零素材文件**——守住 ADR-0009
   的零版权红线，也不引入音频依赖。九类事件音（出牌/摸牌/受伤/回复/濒死/无懈/
   判定/装备/终局琶音），包络为快起缓落，主音量由设置控制。挂在 `enqueueAnimations`
   的事件循环上，与动画同拍错峰；回放不演出也就不发声（M15 的既定行为顺延）。
   AudioContext 在首次调用时才创建/恢复（浏览器自动播放策略），引导层的
   "知道了"按钮恰好提供首个手势。
3. **设置面板（src/settings.ts）**：音效开关、音量、动画节奏（1/1.5/2 倍）、AI
   难度。存 localStorage 独立键（`sanguosha-solo:settings`），与对局存档分离——
   偏好应跨局生效。坏数据容错回默认值。动画节奏作用于动画错峰与 AI 决策间隔
   （演出层倍率，符合 ADR-0009"动画节奏由 UI 层自调"的既定边界）。

## 已知简化（记录在案）

- 难度只有两档且作用面窄：easy 只跳过 MC，不做"故意犯错"的降智；normal 不加强。
  想要真正的难度曲线需要手牌评估与搜索深度调节，留待 AI 里程碑。
- 难度存全局设置而非对局存档——续局后难度以当前设置为准（记录为已知取舍：
  存档格式保持不带 UI 偏好）。
- 音效为程序合成的极简音，不是音效设计；换真素材包仍走 ADR-0009 的本地替换口。
- 动画倍率不改引擎事件顺序，只改呈现间隔；AI 决策间隔同倍率缩放， spectate
  快进由此获得。
- 设置面板不做即时音效试听按钮（出一张牌即可听到）。

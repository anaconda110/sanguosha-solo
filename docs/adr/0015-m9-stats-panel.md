# M9：战绩统计面板

M9 是纯 UI/数据层里程碑，不改引擎：浏览器内批量跑规则 AI 自战并给出胜方分布
与武将出场/胜率，让"平衡性观察"从脚本（probe-*.ts）搬进页面（2026-10-06 定）。

1. **stats.ts**：`runOneGame(seed, acc)` 单局推进 + 累加器（games/sideWins/stepsSum/
   maxSteps/generals）。胜负归属：主公阵营 = zhu+zhong、反贼 = fan、内奸独行；
   平局无人获胜。种子固定 1000+i——同参数的统计完全可复现（与 UI 对局的随机
   seed 互不影响）。
2. **App.vue 面板**：header"战绩统计"按钮展开；跑 20/100 局；每局之间
   `setTimeout(0)` 让出主线程——模拟期间页面与当前对局保持可交互，进度实时刷新。
   结果区：四阵营胜方占比、平均/最长步数、按出场排序的武将表（出场/胜场/胜率）。
3. **首测读数**（20 局）：反贼 60% : 主公阵营 40%；貂蝉胜率 80%（离间+闭月在规则
   AI 对局里过强）、司马懿 0%（鬼才是纯防御技，AI 又只自保——符合预期）；
   平均 869 步。

## 已知简化（记录在案）

- 统计用规则 AI（不含 MC 根决策），只反映规则 AI 生态下的强度，不代表人人
  对战平衡。
- 主线程分批跑而非 Worker：100 局约二三十秒，期间动画/AI 思考共享主线程可能
  略卡；不为统计场景引入第二条 Worker 管线。
- 武将表不区分身份座次（同一武将在主公位与反贼位的胜率混算）。

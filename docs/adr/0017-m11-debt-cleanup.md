# M11：清偿批——PIMC 身份采样、司马懿/周瑜、3 血表、无懈链

M11 不做新功能，专门清偿 ADR-0004 以来挂账的既有缺陷（2026-10-06 定）。

1. **PIMC 身份采样漏减"自己"**：`determinize` 的采样池原以 `['zhu']` 起步，
   循环里 `p.id === viewerId` 直接 `continue`，自己的身份从未从池中扣除。
   后果：隐藏身份多重集 = 五身份 − 主公，**没有减去"我"**——自己是反贼时
   100% 会派生出第三个反贼，忠臣/内奸视角各约 75%，主公视角 0%（所以一直
   没暴露）。修复：采样前先把 viewer 的身份推入 taken（主公已在其中，死者
   视同已亮明）。这不改变确定性——同 seed 仍整局可复现。
2. **司马懿/周瑜技能归属错位**：`GENERAL_SKILLS` 原为 `simayi: ['guicai']`、
   `zhouyu: ['fankui']`——周瑜拿着司马懿的【反馈】，而周瑜自己的技能一个都
   没实现。按标准版还原：**司马懿 = 鬼才 + 反馈**，**周瑜 = 英姿 + 反间**。
   - 英姿（lock）：摸牌阶段多摸一张（`advance` 的 draw 相位加 `yingzi` 判定，
     并记 skill 事件供 UI/回归观测）。
   - 反间（active）：出牌阶段限一次，令一名其他角色猜一种花色，然后展示一张
     手牌交给他；猜错则受到你造成的 1 点伤害。新增 `fanjian` 询问类型与
     `respondFanjian` 动作（UI 四个花色按钮）；`viewOf` 对该询问把 `cardId`
     一律置 -1——猜测者看不到展示牌。
3. **3 血武将表**：`setup` 原为 `maxHp: id === 0 ? 5 : 4`，池内 8 名标准 3 血
   将（司马懿/甄姬/诸葛亮/周瑜/大乔/孙尚香/貂蝉/华佗）全按 4 血跑。新增
   `hpOf(general, seatId)`：3 血表 + 主公位 +1（曹操主公 5 血、貂蝉主公 4 血）。
   这是 M9 战绩面板里"谋士型近乎不死"的部分原因。
4. **无懈链（反无懈）**：ADR-0004 承诺"视需要加"，此后 14 篇 ADR 一直挂着。
   `TrickFrame.negated: boolean` 改为 `wuxieCount: number`：**奇数 = 被抵消**，
   偶数 = 恢复生效。每张无懈打出即翻转并重开一圈询问（`askedWuxieIds` 重置为
   仅含出牌者）——因为"该不该反无懈"是一个新问题。终止性由"无懈是有限手牌 +
   每人一圈内只被问一次"保证。同一机制作用于延时判定帧：奇数张时该延时锦囊
   直接弃置、不判定。
5. **无中生有/桃园结义帧化**：这两张牌原先在 `apply` 里内联结算，**从不询问
   无懈**。现改为压入 TrickFrame 逐目标结算（无中 = 只对自己；桃园 = 从使用者
   起按座次的全部存活角色），对齐官方"每目标都有无懈窗口"。
6. **无懈询问锚点**：从帧的锚点（锦囊使用者 / 延时锦囊的判定区主人）的下家起
   扫一整圈，**锚点最后被问到**——使用者因此有机会反无懈救回自己的锦囊。
7. **AI 无懈策略重写**：先判"我是否希望这张锦囊生效"（三态：希望 / 反对 /
   不关心），再与当前奇偶比对，只有立场与现状相悖时才出牌。这使"反无懈救
   自己的锦囊 / 救主公"自然成立；不关心的（如反贼对队友）仍不掺和。
8. **逐技回归护栏 `scripts/regression.ts`**（`npm run regression`）：不引入测试
   框架，单趟跑 N 局规则 AI 自战，断言 25 个技能各自被发动过（use/lock 类从
   动作流反推，与 probe-m4 同判据）、无懈链深度、卡牌守恒、体力表与技能归属、
   同 seed 确定性；另设**构造局面**（华佗急救、司马懿反馈、周瑜反间窥牌隔离、
   无懈链奇偶）覆盖自战碰不到的单点。`急救` 因触发条件苛刻（需华佗 + 濒死者是
   自己或主公 + 手牌≥2）不进自战期望表，由构造局面覆盖。

## 本轮确定"永久不做"（清偿后挂账降级为定论）

以下此前以"待办"形式挂在各 ADR 里，本次明确为设计取舍，不再视为债务：

- 闭月自动发动、不询问真人（永远划算，省一次点击）。
- 离间的使用者/目标顺序固定为"先选者出决斗"。
- 丈八蛇矛不用于"打出"（南蛮/决斗应答），仅"使用"。
- 贯石斧、流离只能弃手牌（原版可含装备区）。
- 方天画戟多目标 + 丈八两牌的组合引擎支持但 UI/AI 不产生。
- AI 无懈不为反贼队友出头（身份推断属 AI 里程碑，非规则缺口）。
- 天然锦囊不可被转换使用（ADR-0014 已有理由）。

## 已知简化（记录在案）

- 反间的展示牌经 `viewOf` 置 `cardId: -1` 隔离，但完整状态本身对 Worker/MC 仍可见
  ——本作信息隔离一贯只做 UI 层，与前例（观星 guanxingCards）一致。
- 无懈链的重开询问是"每人一圈内只被问一次"，不是严格的"按座次无限循环直到
  无人应答"；后者在多人局里会让同一人反复被问，交互成本高。
- 3 血表按标准版记忆录入；本项目无联网校验手段，若与官方有出入以本表为准。
- 反间猜错才受伤，猜中无任何代价（与原版一致）；AI 猜测一律猜 ♥（无信息可用
  时的最优先验，牌堆构成里红桃最多）。
- 英姿是锁定技（M11 起在摸牌阶段自动生效），不询问"是否发动"。
- 校验：`npm run regression` 全绿（25 技能覆盖 + 无懈链 + 构造局面），
  `npm run smoke` 60 局平均 600 步、卡牌守恒、同 seed 可复现。

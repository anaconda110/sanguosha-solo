# TypeScript + 浏览器 + 从零自研

本项目以学习为目的（2026-10-05 定）：规则引擎、AI、UI 全部从零实现。不 fork 无名杀等现有项目——其 GPL-3.0 协议会迫使本项目整体开源，且阅读几十万行旧代码库偏离学习目标；无名杀（JS/HTML5）与太阳神三国杀（C++/Qt/Lua）仅作为规则与架构的纸面参考，不复制其代码。技术栈选 TypeScript + Vite + DOM 渲染、纯浏览器运行：卡牌游戏无实时性与原生 API 需求，DOM 做卡牌 UI 比游戏引擎（Unity/Godot/Cocos）更直接，且参考项目无名杀即 HTML5 栈，社区经验最易检索；决策者无语言偏好。UI 层选 Vue 3（同日定）：卡牌界面组件化自然，响应式更新省去手写 DOM 同步。后期如需桌面程序，用 Tauri/Electron 包壳即可，不构成推翻成本。

## Consequences

- 规则引擎必须与 UI 严格分离（纯逻辑库），这是包壳与 AI 训练的共同前提。
- 永不把 GPL 代码或其美术素材提交进本仓库；如临时采用无名杀素材包，仅限本地自用。

# M13：补齐两型锦囊——五谷丰登与借刀杀人

标准版 25 张锦囊里，本项目此前缺两型（2026-10-06 定）：五谷丰登与借刀杀人。
两者都不是"再加一张牌"那么简单——它们分别要求"逐目标公开取牌"与"跨玩家的
出杀转委托"，各带来一个新的引擎机制。

1. **五谷丰登（wugu，2 张）**：亮出 X 张（X = 目标数，即存活人数），从使用者
   起按座次逐目标询问取牌（新询问 `wuguPick`，亮出的牌公开可见）。走
   TrickFrame 的逐目标推进，因此**每个目标都有独立的无懈窗口**（M11 的帧机制
   红利）。最后一个目标取完后，剩余的牌进弃牌堆。亮出的牌存在 `frame.wuguCards`
   ——牌在帧里而非某人的手牌，卡牌守恒记账已加入（smoke/regression 同步）。
2. **借刀杀人（jiedao，2 张）**：指定一名**装备了武器**的角色与其攻击范围内的
   一个杀目标，压入 TrickFrame（可被无懈）。结算时若持刀者有杀素材且目标合法，
   开 `jiedao` 询问：出杀 → 视为该角色对指定目标**使用**一张杀（压真实的
   ShaFrame，因此雌雄/铁骑/青龙刀/贯石斧等武器链路全部生效）；不出杀 → 武器
   牌从装备区转交借刀人（`transferWeapon`，含枭姬触发）。
3. **AI**：五谷只在"己方人数 > 敌方人数"时使用；借刀优先挑"敌方持刀者 + 敌方
   杀目标"的组合；应答时手牌≥2 宁可出杀（杀通常比武器便宜）。
4. **UI**：五谷亮出的牌以按钮列出（公开信息）；借刀是两步交互（点持刀者 → 点
   杀的目标），目标高亮随步骤切换。

## 已知简化（记录在案）

- 借刀"出杀"只支持普通杀素材（`canActAsSha`），不支持丈八蛇矛两张当杀。
- 借刀目标校验里禁止了空城角色（与原版裁定一致），但未校验"持刀者杀不到目标时
  直接交武器"以外的边界（如目标中途死亡 → 帧推进时按"无法出杀"处理，交出武器）。
- 五谷亮牌数按"当前存活人数"计算，与原版（使用时的目标数）一致；若有人在结算
  途中死亡，亮出的牌数不会重算，多余的一张最后进弃牌堆。
- 五谷的亮牌信息对所有玩家公开（含 AI），与"手牌暗置"的隔离原则一致——它是
  明置牌，不是泄露。

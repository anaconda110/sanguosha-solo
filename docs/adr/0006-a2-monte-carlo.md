# A2：确定性化蒙特卡洛（PIMC）与 MC/规则分工

AI 第二期采用"根决策蒙特卡洛 + 规则 rollout"（2026-10-05 定）：

1. **MC 只决定出牌阶段**。每个出牌询问枚举 ≤6 个合法候选（含结束出牌），对每个候选：把当前状态确定性化（隐藏手牌/隐藏身份按约束均匀重采样）→ 应用候选 → 用规则 AI 打到终局或 300 步截断 → 按己方阵营胜负计分（截断局面用血量差部分评估，0.5±0.4，避免奖励拖延）。响应类询问（出闪/出杀/求桃/再杀）沿用规则策略——战术上"有闪必闪、能救就救"已接近最优，MC 留给策略层。这是性能与质量的关键分工：每回合仅 1 次约 1-2 秒的 MC 计算，而非每询问。
2. **确定性化（PIMC）**：未知牌池 = 他人手牌 ∪ 牌堆（弃牌堆是公开信息，保留不动），均匀重洗后按各家手牌数重发，余下作新牌堆；隐藏身份按身份多重集约束均匀指派（死者的已亮身份扣除）。实现上读取他人手牌仅用于池化，采样结果与真实手牌内容统计独立——这是 PIMC 标准做法，不构成读牌。它也不属于 ADR-0003 排除的"贝叶斯推理"（无后验更新，纯均匀采样）。
3. **确定性**：MC 采样随机数从公开状态字段哈希派生（seed + 座次 + 手牌数摘要），同一 seed 的整局对局仍完全可复现——冒烟确定性校验在 MC 路径上依然成立，回放不受影响。
4. **性能前提**：本次同步清偿 ADR-0004/0005 期间的克隆债——step() 不再深拷贝日志与动作日志（两者纯追加，引用共享 + 局部缓冲后整表拼接），深拷贝仅覆盖可变游戏状态。此前 seed 51/57 的 2000+ 步马拉松局每步都在深拷贝上千条日志，是该热点最坏的展现。

已知取舍：AI 思考时同步阻塞 UI 线程 1-2 秒（单人回合制可接受，Web Worker 列入 M3 备选）；身份采样是均匀先验，无行为推断。
